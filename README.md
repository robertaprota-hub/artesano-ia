# Artesano · IA

App das 4 turmas do programa de capacitação em IA da Artesano Urbanismo, conduzido pela prota.ia.
Notícias do mercado imobiliário, aulas, materiais e agenda. Site estático, sem build, publicado no GitHub Pages.

- `index.html` — o app inteiro. Dados das turmas e das aulas no bloco `<script>` (TURMAS, AULAS).
- `manifest.webmanifest`, `icon-*.png` — para adicionar à tela inicial do celular.
